## 2. 訴求の骨格

大手飲食チェーンは「店舗・現場に刺さっても本部の稟議に上がらない」構造がある。
そこを **入口の高さの問題** と定義し、以下の2つの差別化で解く、という組み立て。

1. **中計はめ込み** — 1社ずつ中期経営計画を読み込み、手紙のタイトルから本文まで書き下ろす。それを量産できる仕組みがある
2. **秘書攻略** — 「秘書と受付は人種が違う」。事務連絡のトーンで秘書室に繋ぎ、返信期日まで握る

結果として「アウトバウンドなのにインバウンドのように決まる」「社長の命を受けた決裁者が出てくる」。

## 4. 意図的に「載せなかった」もの

- **クライアント各社の実名**
  社内のトークスクリプトには実名の事例が複数ありますが、**Web上での掲載許諾が確認できていない**ため、
  LPでは「東証プライム上場・日用品メーカー」等の業種表記に伏せています。
  → 対象企業と許諾状況は社内 Notion「商談トークスクリプト完全版」を参照。
  　許諾が取れ次第、`index.html` の `#proof` セクション（HTMLコメントあり）を実名に差し替えてください。

- **受注金額の具体値**
  同じく個社が特定されうるため未掲載。商談時の個別開示としています。

- **コース別の詳細価格（33万／50万など）**
  「目安のみ載せる」方針のため、月額15万円〜という下限のみ提示。

- **飲食チェーンの実績社名**
  現時点で飲食チェーンの実績を確認できていないため、事例は他業種のものを業種表記で掲載しています。
  飲食チェーンでの実績が出たら差し替えると訴求力が上がります。

## 4-2. 素材の取り扱いルール（重要）

2026-07-28、マスキング前の素材原本を誤って公開リポジトリにコミット・push する事故が発生した。
返信メールのスクリーンショットには、先方担当者とクライアント代表者のメールアドレスが写っていた。
再発防止のため、以下をルールとする。

1. **マスキング前の原本は `_private/` にのみ置く。** `.gitignore` で除外済み。ルート直下の
   `*.png` / `*.jpg` も除外しているため、原本を置き忘れてもコミットされない
2. **公開用画像は `assets/img/` に、マスキング済みのものだけを置く**
3. **マスキングは画素を塗りつぶす**。CSSやHTMLで隠す方法は、元画像がそのまま配信されるため不可
4. コミット前に `git add -A --dry-run` で、意図しないファイルが混ざっていないか確認する

### ワタミ様事例のマスキング範囲

掲載許諾が未取得のため、両社を匿名化して掲載している。塗りつぶした箇所は以下。

- 封筒：郵便番号・所在地・社名・宛名（**役職「代表取締役会長 兼 社長CEO」は残す**——社長宛に送った事実が訴求の核のため）
- 返信：件名の社名/担当者名、差出人・宛先のメールアドレス、宛名のクライアント社名・代表者名、
  本文中の社名・担当者名・代表者名、および企業が特定される固有の施策名の行

許諾が取れた場合は、`_private/` の原本から実名版を作り直して差し替える。
