# 映像生成プロンプト【ペイン可視化 → 手紙が壁を越える】

LP（大手飲食チェーン開拓なら｜かざあな隊）の**ファーストビュー背景**および**SNS広告**用の動画を生成するためのプロンプト。
動画生成AI（Sora / Veo / Runway 等）にそのまま貼り付けて使用する。素材を差し替えれば他業界版にも流用可。

- 用途：LP背景（16:9）／ X広告・リール（9:16）
- 尺：20〜25秒
- 関連：`index.html` の `.hero` セクション

---

## プロンプト本体（このブロックをコピーして使用）

```text
あなたはシネマティックな短編映像クリエイターです。
以下の条件で、20〜25秒の「B2B営業のペインが一目で伝わり、一通の手紙がそれを突破する」映像を生成してください。

【必須素材】

添付した「実際のかざあな隊の手紙の写真」（和紙の質感・A4の文面・封筒・宛名の毛筆感を忠実に再現。文字を書き換えない）
添付した「大手企業から実際に届いた返信メールのスクリーンショット」（マスキング済。最終カットで使用）
ブランドカラー：ネイビー（#1B2A4A系）を基調に、手紙と光の演出のみゴールド（#C9A227系）
もし参考映像があれば、そのカメラワークや雰囲気を自然に取り入れる

【コアコンセプト】
前半は「大手飲食チェーン本部に届かない営業」の閉塞感を、寒色・静止・遮断のモチーフで描く。
後半は一通の和紙の手紙だけが、受付でも担当者でもなく、ビルの最上階＝社長の机まで静かに"浮上"していき、
社長のひと言の指示が、決裁者からのメールとなって主人公のスマホに届く。
色調は「寒色の閉塞 → 手紙の登場でゴールドの光が差す」へと転調させ、ペインと突破を色で語る。

【タイムライン（動きを細かく指定）】
0-4秒（ペイン①：見上げる壁）：
夕暮れ、ガラス張りの巨大な本社ビルを真下から見上げるローアングル。ビルは冷たいネイビーグレー。
スーツの営業パーソンの後ろ姿が小さく画面下に立つ。カメラはゆっくり上へティルトし、ビルの高さ＝入口の高さを強調。
窓の明かりが規則正しく並ぶが、どの窓も遠い。

4-9秒（ペイン②：遮断の連打）：
短いカットを静かに3つ重ねる。
(1) 受付の内線電話が「ツー…」と切れ、受話器が置かれるアップ。
(2) PC画面の「送信が完了しました」の文字が、無数の未読メール一覧の中へスクロールして沈み、埋もれていく。
(3) 展示会の名刺の束が箱の中で他の名刺に埋まり、照明が落ちて暗転。
すべて寒色・無音に近い環境音のみ。人物の表情は映さず、モノの動きだけで「届かない」を語る。

9-14秒（転調：手紙の登場）：
暗転から一転、柔らかな光の中に、添付写真の和紙の手紙がひらひらと舞い上がる。
紙の繊維・折り目・宛名の質感を忠実に。ここで初めてゴールドの光が画面に差す。
手紙はビルの外壁に沿ってゆっくり"上昇"していく。ガラス越しに各フロア（受付、会議室、執務室）が流れ、
どの階にも止まらず、最上階へ。カメラは手紙を追って滑らかに上昇するワンカット風。

14-19秒（突破：社長の机へ）：
最上階の静かな社長室。木目のデスクに手紙がすっと着地し、ゆっくり開かれる。
手紙のタイトル部分（先方の施策名が入った一行）に淡いゴールドの光が走る。
社長の手（顔は映さない）が万年筆で余白に短い指示を書き、手紙を秘書へ差し出す。紙の音だけが響く。

19-25秒（結果：メールが届く）：
場面転換。冒頭の営業パーソンのスマホが暗い机の上で点灯し、通知が浮かぶ。
画面には添付した実際の返信メールのスクリーンショット（マスキング済）。
「社長の◯◯より指示をいただきご連絡しております」の一文にだけ、じわりとハイライト。
スマホを手に取る手のアップ、背景に朝の光。ロゴ「かざあな隊」とコピーが静かにフェードインして終了。

【映像スタイル】

シネマティック、浅い被写界深度、ワンカットに近い滑らかなカメラワーク
前半：寒色（ネイビー・グレー）、コントラスト強め、動きは「止まる・切れる・埋もれる」
後半：手紙の登場以降のみ暖色のゴールドが混ざる。派手にしすぎず、光は常に紙の周辺だけ
実写の手紙写真・メールスクショの質感を絶対に崩さない（紙の凹凸、インクの濃淡、画面のUIをそのまま）
音楽はなし、または静かなピアノ。紙の音・受話器の音・通知音の3つを効果音の主役にする
アスペクト比：LP背景用は16:9、X広告・リール用は9:16を別途書き出し

【禁止事項】

手紙の文字・メール文面を勝手に書き換えない、創作しない
実在の飲食チェーンのロゴ・店舗・看板を映さない（ビルは無地のオフィスビルとする）
人物の顔をはっきり映さない（後ろ姿・手元のみ。特定人物を想起させない）
派手なCG感、紙の不自然な変形、炎・爆発などの過剰演出
テキスト字幕の過剰表示（表示するのは最後のロゴとコピー1行のみ）
「保証」「必ず会える」を想起させる演出（あくまで一つの成功の瞬間として描く）

添付した「実際の手紙」と「実際に届いた返信メール」を主役に、
"届かなかったものが、届いた"瞬間の静かなカタルシスを描いてください。
```

## 実行メモ

プロンプト本体は上記のまま使用する前提で、実制作時に詰めておきたい論点。

### 1. 尺は分割生成が前提

主要な動画生成AIは1回あたりの生成尺が短く（多くは8〜10秒程度）、20〜25秒を一発で出すのは難しい。
タイムラインが5ブロックに分かれているため、**ブロックごとに生成 → 編集で連結**する運用を想定する。

| ブロック | 尺 | 内容 |
|---|---|---|
| A | 0-4秒 | 見上げる本社ビル |
| B | 4-9秒 | 遮断の連打（3カット） |
| C | 9-14秒 | 手紙の登場・上昇 |
| D | 14-19秒 | 社長室・着地 |
| E | 19-25秒 | スマホに返信が届く |

ブロック間の色調（前半：寒色／後半：ゴールド混ざり）は、編集時のカラーグレーディングで揃えるほうが破綻しにくい。

### 2. 実写素材（手紙・返信メール）は「合成」が確実

生成AIは**画像内の文字を正確に再現できない**。「文字を書き換えない」という指示を出しても、
手紙の文面やメールのUIは高確率で崩れる。

→ 手紙とメールスクショが主役になるブロック **C・D・E** は、
　背景・カメラワークだけをAIで生成し、**実写素材は後段の編集ソフトで合成**するのが確実。

### 3. 実際の返信メールを広告に使う場合は要許諾

マスキング済みであっても、先方企業から届いたメールを広告素材に使うことには相手方の許諾が要る。
LP側では同じ理由でクライアント実名を伏せている（`LP設計メモ.md` 参照）ため、**判断を揃えること。**

代替案：実物のスクショではなく、**文面を再現した自社作成のモックアップ**を使えばこの論点を回避できる。
「実際に届いた」という表現を使う場合は、あくまで事実の範囲にとどめる。

### 4. LP背景として使う場合の要件

ファーストビュー背景に敷く前提なら、以下を満たすと扱いやすい。

- **無音で成立すること**（LP背景は自動再生＝ミュートが前提）
- **ループしても違和感がないこと**、または1回再生後に静止画へ切り替える
- **ファイルサイズを抑えること**（目安 2〜3MB以下。重いとLPの表示速度を損なう）
- **文字が乗る領域を確保すること**（見出し・CTAが乗る左側は情報量を落とす）
- モーションを減らす設定の利用者向けに、**静止画へのフォールバック**を用意する

現状の `index.html` のヒーローはCSSグラデーションで背景を作っている。
動画を採用する場合は `.hero__bg` を `<video>` に差し替える改修が必要。
